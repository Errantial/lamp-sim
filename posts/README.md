# posts

Drop a file here and push to `main`. Vercel rebuilds ecg.name in about a minute.

- `2026-11-20-my-post.md` shows up as **my post** (or the first `# heading`), dated 2026-11-20, at `/posts/my-post/`
- `.html` files are served as they are; anything else (pdf, png, ...) is linked directly
- The date prefix is optional. Dated posts are listed newest first
- To remove a post, delete its file

Upload from a browser: https://github.com/Errantial/lamp-sim/upload/main/posts
